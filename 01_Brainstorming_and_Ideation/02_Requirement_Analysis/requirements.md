# Requirement Analysis

## Project Title
Streamlining IT Procurement: Automating Standard Laptop Orders with Flow Designer

## Functional Requirements

- The system should allow standard laptop order requests to be processed.
- The system should automate the defined procurement workflow.
- The workflow should support the required approval process.
- The system should update the request based on the workflow stages.
- The system should provide a clear final status for the laptop order.

## Non-Functional Requirements

- The workflow should be easy to use.
- The system should process requests efficiently.
- The workflow should be reliable and consistent.
- The system should maintain proper tracking of requests.
- The system should provide a simple and understandable process.

## Software Requirements

- ServiceNow
- Flow Designer
- Web Browser
- Internet Connection

## Hardware Requirements

- Computer or Laptop
- Minimum 4 GB RAM
- Stable Internet Connection

## Users

- IT Employees
- IT Procurement Team
- Approver / Manager

## Expected Output

An automated workflow for processing standard laptop orders through Flow Designer.
