# Project Design

## Project Title
Streamlining IT Procurement: Automating Standard Laptop Orders with Flow Designer

## System Design

The system is designed to automate the standard laptop procurement process using Flow Designer.

## Process Flow

1. Employee submits a standard laptop request.
2. The request is received by the system.
3. The Flow Designer workflow is triggered.
4. The request goes through the required approval process.
5. The request is processed based on the defined conditions.
6. The request status is updated.
7. The laptop order process is completed.

## Workflow Components

- Request
- Flow Designer
- Approval
- Conditions
- Automated Actions
- Request Status
- Final Output

## Expected Design Outcome

The designed workflow provides a structured and automated process for handling standard laptop procurement requests.
