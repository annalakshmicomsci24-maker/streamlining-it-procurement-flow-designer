# Project Documentation

## Project Title

Streamlining IT Procurement: Automating Standard Laptop Orders with Flow Designer

## Project Overview

This project focuses on streamlining the IT procurement process by automating standard laptop orders using Flow Designer.

## Project Objective

The main objective is to reduce manual activities and create a structured workflow for processing standard laptop requests.

## Technologies Used

- ServiceNow
- Flow Designer
- Web Browser

## Project Workflow

1. Laptop request is submitted.
2. The Flow Designer workflow is triggered.
3. The request goes through the required approval process.
4. Conditions are evaluated.
5. Automated actions are performed.
6. Request status is updated.
7. The laptop order process is completed.

## Benefits

- Reduces manual work.
- Improves process efficiency.
- Provides a structured procurement workflow.
- Makes request processing easier to track.
- Helps standardize laptop ordering.

## Testing

The workflow was tested using different request scenarios to verify the expected behavior.

## Conclusion

The project provides an automated approach for handling standard laptop orders through Flow Designer and helps streamline the IT procurement process.
