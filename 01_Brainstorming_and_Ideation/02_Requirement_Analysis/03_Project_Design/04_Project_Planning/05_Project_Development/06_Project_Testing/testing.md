# Project Testing

## Project Title
Streamlining IT Procurement: Automating Standard Laptop Orders with Flow Designer

## Testing Objective

To verify that the Flow Designer workflow processes standard laptop orders correctly according to the defined requirements.

## Test Cases

| Test Case | Scenario | Expected Result | Status |
|---|---|---|---|
| TC01 | Submit a valid laptop request | Request should be processed | Pass |
| TC02 | Submit a request with missing information | Request should be handled according to validation rules | Pass |
| TC03 | Submit request for approval | Approval process should be triggered | Pass |
| TC04 | Approved request | Workflow should continue to the next stage | Pass |
| TC05 | Rejected request | Workflow should handle the rejection correctly | Pass |
| TC06 | Complete laptop order process | Request status should be updated | Pass |

## Testing Result

The workflow was tested using different request scenarios. The expected workflow behavior was verified for the defined test cases.

## Conclusion

The testing confirms that the designed Flow Designer workflow supports the standard laptop order process according to the defined requirements.
