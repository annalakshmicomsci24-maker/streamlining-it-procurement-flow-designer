# Project Development

## Project Title
Streamlining IT Procurement: Automating Standard Laptop Orders with Flow Designer

## Development Overview

The project is developed using Flow Designer to automate the standard laptop procurement process.

## Development Steps

1. Create the required procurement request process.
2. Configure the required fields and conditions.
3. Create a flow in Flow Designer.
4. Configure the flow trigger.
5. Add the required approval and action steps.
6. Configure conditions for processing the request.
7. Configure the required status updates.
8. Activate and execute the workflow.
9. Verify the final output.

## Flow Designer Workflow

Request Submission
→ Flow Trigger
→ Approval
→ Conditions
→ Automated Actions
→ Status Update
→ Final Output

## Development Tools

- ServiceNow
- Flow Designer
- Web Browser

## Development Outcome

The workflow automates the defined standard laptop order process and helps reduce manual activities in IT procurement.
