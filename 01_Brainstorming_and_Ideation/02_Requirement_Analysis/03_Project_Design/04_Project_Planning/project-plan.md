# Project Planning

## Project Title
Streamlining IT Procurement: Automating Standard Laptop Orders with Flow Designer

## Project Goal

To develop an automated workflow for processing standard laptop orders using Flow Designer.

## Project Activities

1. Understand the existing laptop procurement process.
2. Identify the required requirements.
3. Design the procurement workflow.
4. Configure the Flow Designer workflow.
5. Test the workflow with different scenarios.
6. Document the project.
7. Demonstrate the completed project.

## Project Timeline

| Phase 5 | Project Development |

## Tools and Technologies

- ServiceNow
- Flow Designer
- Web Browser

## Expected Result

A functional workflow that streamlines the process of standard laptop orders and reduces manual procurement activities.
